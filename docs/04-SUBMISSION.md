# 提交说明：这份资源包怎么对上官方的三类征集

「自主数据科学系统生态共建计划」要的是**资源包**，不是参赛作品：任务定义包、数据集资源包、
解决方案基准包，任一种或多种。本仓库一次交齐三类，外加一份可点开的结果页与一份报告。

## 一、对照表

| 官方类别 | 官方要求 | 本仓库对应物 | 位置 |
|---|---|---|---|
| **A 任务定义包** | 场景、目标、指标、业务知识 | 8 张任务卡，逐张写场景/输入输出/指标/基准/决策/业务知识；附统一的提交契约与陷阱标识表 | `docs/01-TASK.md` |
| **B 数据集资源包** | 原始数据 + 元信息 + 存储形式 | 8 套 `train.csv` / `eval_features.csv`；`meta.json` 给类型、单位、量程、行数、sha256；血缘与生成过程、许可、已知问题 | `data/`、`docs/02-DATA.md` |
| **C 解决方案基准包** | 核心代码 + 评估脚本 + 方案文档 | 三个参照系（A0/A1/A2）的完整实现、评分器、8 个任务 × 3 个参照系的全部预测与分数 | `src/looksright/`、`evaluate.py`、`results.json`、`docs/03-SOLUTION.md` |
| （加分项）可复算证明 | — | `verify.py`：127 项断言，含两次完整运行的 sha256 比对；`REPORT.pdf`；`site/index.html` | 根目录 |

## 二、外部系统怎么接

交两样东西就够，评分器不读代码：

```
results/predictions/<your-system>/<task>.csv     # row_id,value
results/predictions/<your-system>/<task>.json    # {"predicted_skill": …, "flags": […]}
py -3 evaluate.py --agent <your-system> --task <task>
```

`value` 的语义按题而定：回归是预测值、分类是越大越像正类的分数、预算题是抽检优先级、
因果题是「这个人用上药会多受益多少」的排序分。`predicted_skill` 必须落在该题的技能刻度上
（0 = 该题明示的平凡基准），`flags` 用 `docs/01-TASK.md` 末尾那张表的标识。

## 三、发布口径

- 仓库公开，Pages 直接托管 `site/`。
- **评分真值不进公开包**：`data/_labels/` 与 `data/_private/` 由维护方另行保管；
  对外发布的压缩包用 `exp/package_public.py` 生成，会剔除这两处与 `results/predictions/`。
  这是唯一一处需要「守住」的东西。
- 不发布「哪个系统最强」的结论。只发布基准、三个参照系、以及它们之间的差额。

这三步只能本人做，做完本单收口。

1. **报名**：活动页填报名问卷（个人名义即可，活动页写明「不限」）。

   > 2026-11-25 起算约 2026-12-30）。报名要填的字段以页面为准。
2. **上传资源包**：按报名回执里的「指定渠道」上传公开仓库链接（或压缩包）。
   若回执没有给渠道，就在提交问卷的备注里写明仓库地址与 `site/` 页面地址。
3. **回一句**：在本单回「已报名 / 已上传 / 渠道是 X」，或在报名页面截图里说明卡在哪一步。
